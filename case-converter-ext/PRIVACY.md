# Privacy Policy / Chính sách bảo mật

_Last updated / Cập nhật lần cuối: 2026-09-12_

## English

Case Converter does not collect, store, or transmit any personal data, browsing history, or page content to any server. All text transformations happen locally, inside your browser.

- **No analytics or tracking** of any kind.
- **No remote code** is executed by this extension.
- **Settings** (theme, language, font, shortcuts, excluded sites) are stored locally using the standard `chrome.storage.sync` API, which syncs only across your own signed-in Chrome profile via your Google account — this data never passes through the developer's servers.
- **Host permissions** (`<all_urls>`) are used solely so the in-page keyboard shortcuts can transform text inside the field you are actively editing, on whichever site you choose to use them. The extension never reads, logs, or transmits page content elsewhere.

Questions? Open an issue on the project's GitHub repository.

## Tiếng Việt

Case Converter không thu thập, lưu trữ hay truyền tải bất kỳ dữ liệu cá nhân, lịch sử duyệt web, hay nội dung trang nào lên bất kỳ máy chủ nào. Toàn bộ việc chuyển đổi văn bản diễn ra cục bộ, ngay trong trình duyệt của bạn.

- **Không có công cụ phân tích hay theo dõi** dưới bất kỳ hình thức nào.
- **Không thực thi mã từ xa** trong tiện ích này.
- **Cài đặt** (chủ đề, ngôn ngữ, phông chữ, phím tắt, danh sách trang bị tắt) được lưu cục bộ qua API tiêu chuẩn `chrome.storage.sync`, chỉ đồng bộ trong phạm vi hồ sơ Chrome đã đăng nhập của chính bạn thông qua tài khoản Google — dữ liệu này không bao giờ đi qua máy chủ của nhà phát triển.
- **Quyền truy cập trang** (`<all_urls>`) chỉ được dùng để phím tắt trong trang có thể chuyển đổi văn bản trong ô bạn đang chỉnh sửa, trên trang bạn chọn sử dụng. Tiện ích không bao giờ đọc, ghi lại, hay truyền nội dung trang đi nơi khác.

Có câu hỏi? Hãy mở một issue trên kho mã nguồn GitHub của dự án.
