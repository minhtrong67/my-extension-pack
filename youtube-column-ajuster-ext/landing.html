Frequently asked questions

Does this extension collect any data?

No. YouTube Column Ajuster runs entirely on your device, stores settings locally with chrome.storage, and never sends anything over the network.

Will it break when YouTube updates its design?

The extension targets YouTube's grid components with resilient CSS selectors and is actively maintained to track YouTube's markup changes.

Can I use different column counts on different pages?

Yes — enable "Set a different value per page" in Settings → Layout to configure Home, Subscriptions and Channel independently.

Is my configuration backed up anywhere?

You can export it to a JSON file at any time from Settings → Data, and import it again on any device.
